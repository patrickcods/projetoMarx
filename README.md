## 🎯 Sobre o Projeto

O **Capital Digital** é uma aplicação web desenvolvida como **Atividade Extensionista II** do curso de **Análise e Desenvolvimento de Sistemas** (Centro Universitário Internacional UNINTER). 

O objetivo do projeto é combater a exclusão digital e promover a leitura crítica da obra *O Capital*, de Karl Marx. A ferramenta realiza a transposição didática de conceitos teóricos densos em micro-conteúdos acessíveis, acompanhados de um **Glossário Marxista** interativo e caixas explicativas (`💡 Explicando:`), garantindo alta acessibilidade cognitiva.

---

## 🚀 Tecnologias Utilizadas

A aplicação foi construída priorizando o desenvolvimento *front-end* limpo, garantindo baixíssimo consumo de dados e alta performance para celulares com hardware antigo:

- **HTML5:** Estruturação semântica e acessível do conteúdo.
- **CSS3:** Estilização responsiva com foco na leitura fluida em telas móveis.
- **JavaScript (Vanilla):** Dinamismo e lógica de navegação sem dependências pesadas.
- **GitHub Pages:** Hospedagem em nuvem de acesso público.

---

## 📱 Recursos da Aplicação

- **Design Responsivo:** Otimizado para navegação via smartphones.
- **Glossário Interativo:** Definição simplificada de conceitos centrais da Economia Política (*Mercadoria*, *Valor de Uso* e *Valor de Troca*).
- **Caixas de Leitura Guiada:** Blocos pedagógicos para desmistificar trechos complexos do autor.
- **Acessibilidade para Redes Limitadas:** Código ultra-leve sem frameworks pesados, pronto para funcionar em Wi-Fi público ou conexões 3G/4G instáveis.
